TrackFlow

Java 21, Spring Boot 4, Spring Cloud Gateway, Eureka, Kafka, PostgreSQL, Angular 22, Docker

An order and delivery system: customers place orders, riders deliver them while showing up live on a map, and an admin can see everything. I built it to get more practice with microservices, Kafka and Docker than I'd had at work, and it's the biggest thing I've made on my own.

  • The order and delivery services each have their own PostgreSQL database and never call each other directly. Everything between them goes through Kafka events.
  • Login lives in the gateway: hashed passwords, signed JWTs, and a logout that really invalidates the token. There are three roles (admin, customer, rider), and each service checks that you own what you're asking for.
  • I spent time on the failure cases: events are only sent after the database commit, a duplicate event can't break anything, and messages that keep failing go to a dead-letter topic.
  • The front end is Angular 22 with signals. Riders can share their phone's GPS while delivering.
  • The whole thing, including databases, Kafka and the front end, starts with one docker compose up.

Space Wars

Java 21, java.util.concurrent, Swing, Maven

A small Space Invaders clone I made to actually see how a Java thread pool behaves. Every enemy and every bullet is a task on a ThreadPoolExecutor, and the sidebar shows what each worker thread is doing while you play.

  • There are two bounded pools, one for enemies and one for bullets. Make a pool smaller with its slider and you can watch the queue fill up, then new enemies get rejected outright.
  • Blue enemies freeze when you hit them. Their thread really is asleep (TIMED_WAITING) until you hit them again or they thaw after five seconds.
  • All the numbers in the sidebar come from the executor itself (active count, queue size, completed, rejected), so you can also watch idle threads time out and shut down.

QuakeWatch

Angular, TypeScript, RxJS, signals, globe.gl

A live dashboard that puts every earthquake from the last 24 hours on a 3D globe, using the public USGS feed.

  • The feed refreshes every minute through one shared stream, so the whole app makes a single request.
  • The stats on top (count, strongest, average magnitude, regions) are all computed from one signal.
  • Quakes are coloured and sized by magnitude, and you can filter by size or region.
